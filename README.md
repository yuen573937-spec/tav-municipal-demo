# TAV 窓口横断AI デモ

自治体の対面相談を想定した、ブラウザで操作できる静的HTMLのプロトタイプです。

## 動かし方

`index.html` をブラウザで開くだけで動作します。インストールやサーバーは不要です。

1. 「A窓口」で同意確認にチェックを入れ、「サンプル会話を取り込む」をクリック
2. AI整理結果を確認し、メモを編集して「B窓口に共有」
3. 「B窓口」で前窓口の内容を確認し、未確認事項にチェックを入れて対応を記録
4. 「TD連携｜BI分析」で月・相談テーマを絞り込み、CSVを出力

## GitHub Pages で公開

1. GitHub で新規リポジトリを作成
2. `index.html` と `README.md` をルートにアップロード
3. Settings → Pages → Build and deployment → Deploy from a branch を選択
4. `main` ブランチの `/ (root)` を選び保存
5. 発行された公開URLを共有

**注意**：GitHub Pages で公開した場合、誰でもアクセスできる設定になり得ます。デモは架空データのみを使い、実際の相談内容・個人情報は載せないでください。

## 技術・制限

- HTML/CSS/JavaScriptのみ。外部ライブラリ不要。
- 会話取り込みはサンプル文面の疑似表示。録音・文字起こし・AI推論は未実装。
- A→B窓口共有は同じブラウザ上の状態更新のみ。複数端末間の同期は未実装。
- BIは架空の9行の集計データを使用。Treasure Dataとは未接続。
- 実装にはTAVの実機仕様・API、同意、認証・権限管理、相談ID、保存管理、既存システム連携等の検証が必要です。
